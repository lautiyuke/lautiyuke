### [Yukesoft Tools](https://tools.yukesoft.net)

A collection of free browser-based tools for working with files, images, PDFs, QR codes, GIFs, and more.

One of the main principles behind the project is **privacy**.

File processing happens directly in the user's browser whenever possible. Files don't need to be uploaded to a server just to perform operations such as converting, reorganizing, editing, or processing them.

**Your files stay on your device.**
